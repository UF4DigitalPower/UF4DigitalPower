# Power v1.1.0 Changelog

## 2026-06-16

- 正式发布 v1.1.0
- 适用设备：F4CP-POWER / STM32G474CBT6
- 重构输出禁用路径，关断时同步清理控制状态，降低旧参考值残留导致的异常输出风险
- 恢复并完善输入电压保护逻辑：无输入保持等待，运行中输入掉电进入故障保护
- 重构电源控制逻辑和风扇控制机制，上位机可直接接管风扇设定
- 优化 Buck / Mix / Boost 模式切换准备流程，切模前预计算 duty 并注入控制环，减少模式切换硬跳
- 更新 CMake 构建配置、build.ps1 构建脚本和项目 README 文档
- 基于 git 提交：4658f4b、2a42d34、39e2122、cd0f2e6
- 发布日期：2026-06-16
