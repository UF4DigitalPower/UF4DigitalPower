# 代码审查与控制环路分析

基于当前代码结构和前面整理的硬件参数：

- 电感：22µH
- 输出电容：630µF
- 开关频率：200kHz
- 电流采样：7mΩ × 20
- 最大升压比：约 1:2

对当前控制代码进行分析如下。

---

# 1. 当前架构评价

当前控制器已经属于标准双环控制结构：

```text
Vref
 │
 ▼
电压环（1kHz）
 │
 ▼
Iref
 │
 ▼
电流环（200kHz）
 │
 ▼
Duty
 │
 ▼
Buck-Boost 功率级
```

相比早期：

```text
Vref → PID → Duty
```

单环方案更合理。

优点：

- 电压环和电流环职责分离
- 更容易实现 CV / CC
- 限流更自然
- Boost 模式更稳定
- 后续可以直接做环路设计

---

# 2. 电流环频率过高

代码：

```c
#define POWER_CTRL_FAST_LOOP_HZ 200000U
```

当前：

```text
PWM = 200kHz
Current Loop = 200kHz
```

即：

```text
每个PWM周期执行一次PID
```

PWM周期：

```text
Ts = 5us
```

实际流程：

```text
ADC采样
↓
ADC转换
↓
DMA更新
↓
中断进入
↓
PID计算
↓
PWM更新
```

整个链路存在：

```text
1~1.5个PWM周期延迟
```

约：

```text
5~7.5us
```

因此电流环实际带宽不可能接近200kHz。

工程经验：

```text
PWM = 200kHz
Current Loop = 20~50kHz
Voltage Loop = 500~1000Hz
```

更合理。

因此：

> 当前200kHz电流环调度频率远高于实际可实现控制带宽。

---

# 3. 当前电流环参数缺乏物理依据

代码：

```c
KP = 6
KI = 3
KD = 1
```

看起来属于经验参数。

根据当前采样链路：

## 电流采样增益

```math
K_i = 7mΩ × 20
```

```math
K_i = 0.14V/A
```

ADC：

```math
3.2806V / 4095
```

约：

```math
0.4005mV/count
```

得到：

```math
682count/A
```

即：

```text
1A误差 ≈ 341 counts
```

则：

```c
KP = 6
```

意味着：

```text
1A误差
↓
输出约4092 Tick
```

已经属于很大的控制增益。

因此后面大量：

```c
Clamp()
Integral Limit
Shift
```

实际上是在修正过大的环路增益。

---

# 4. 建议取消KD

当前内环：

```c
i0 =
Integral
+ KP*e0
+ KD*(e0-e1);
```

其中：

```math
e0-e1
```

本质是离散微分。

但电流反馈来自：

```text
ADC
↓
采样噪声
↓
PWM噪声
↓
量化误差
```

因此：

```math
e0-e1
```

通常以噪声为主。

数字电源工程中：

```text
Current Loop → PI
Voltage Loop → PI
```

最常见。

对于：

- Buck
- Boost
- Buck-Boost

电感电流本身已经是一阶系统。

一般无需D项。

建议：

```c
POWER_CTRL_CURRENT_LOOP_KD = 0;
```

先观察稳定性。

# 5. 电压环频率设置合理

代码：

```c
#define POWER_CTRL_VOLTAGE_LOOP_HZ 1000U
```

硬件参数：

```math
L = 22uH
```

```math
C = 630uF
```

LC双极点：

```math
f_{LC}
=
\frac{1}{2\pi\sqrt{LC}}
```

约：

```math
1.35kHz
```

因此：

```text
Voltage Loop = 1kHz
```

是合理的。

预计最终闭环交越频率：

```text
400~700Hz
```

比较合适。

建议目标：

```text
电压环交越频率：
500Hz左右
```

---

# 6. MIX模式本质偏向Boost

当前：

```text
MIX
↓
IIN反馈
↓
Boost调制
↓
Buck同步
```

实际更接近：

```text
Boost控制
```

而不是真正Buck-Boost控制。

例如：

```text
Vin = 24V
Vout = 26V
```

此时：

```math
D = 1-\frac{24}{26}
```

约：

```math
7.7%
```

Boost占空比已经非常小。

仍然使用：

```text
Boost主调制
```

会导致：

- 分辨率下降
- 灵敏度变化
- 控制增益突变

建议：

```text
Buck:
Vout < 0.9Vin

Boost:
Vout > 1.1Vin
```

中间区域：

```text
固定Buck≈95%
Boost负责调节
```

或：

```text
固定Boost≈5%
Buck负责调节
```

避免完全按照Boost方式工作。

---

# 7. 模式切换时直接清PID存在风险

代码：

```c
if(mode_changed)
{
    reset_pid();
}
```

会清除：

```text
积分项
误差历史
```

例如：

```text
24V
↓
25V
↓
26V
```

经过边界时：

```text
积分项清零
```

可能产生：

```text
Duty跳变
```

导致：

- 输出电压跌落
- 输出电压过冲
- 模式边界振荡

建议：

保留：

```text
Integral
```

仅清除：

```text
D项
误差缓存
```

或者：

```text
积分项限幅迁移
```

实现无扰切换。

对于：

```text
L = 22uH

fs = 200kHz
升压比 ≤ 2
```

建议目标：

电流环：

```text
fc = 3~5kHz
```

电压环：

```text
fc = 300~700Hz
```

相位裕度：

```text
50°~70°
```

增益裕度：

```text
> 6dB
```

此时：

- Buck稳定
- Boost稳定
- MIX模式更容易处理
- 不容易触碰RHPZ限制

---

# 总结

当前代码最大的优点：

- 双环结构正确
- 状态机清晰
- 软启动设计合理
- CV/CC实现规范
- 快慢环分离明确

当前最需要关注的问题：

1. 电流环200kHz调度频率过高。
2. 电流环KP/KI/KD缺乏模型支撑。
3. KD项可能放大采样噪声。
4. MIX模式本质偏向Boost。
5. 模式切换时直接清PID可能产生扰动。

相比PID参数本身，更应优先观察：

```text
Mode切换
Iref连续性
Integral状态
Duty连续性
```

很多看似“环路振荡”的问题，实际上来自模式切换、积分饱和和软启动限幅，而不是真正的PID参数错误。
